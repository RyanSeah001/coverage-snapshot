# Coverage Snapshot

A one-page insurance coverage summary built from Great Eastern ePartner policy detail pages.

## How to use

1. In ePartner, open a client's **Policy Detail** page.
2. Save it (Ctrl+S, "Webpage, HTML only") and drop the file into the app, or press Ctrl+A, Ctrl+C and paste the text.
3. Repeat for each in-force policy. You can also add the **Policy Listing** page to list surrendered or withdrawn policies.
4. Pick the person under **Coverage for**, then click **Save as PNG**.

## Privacy

Everything runs in the browser. Uploaded pages are not sent anywhere or stored. The sample client that loads first uses made-up figures.
Do not commit real client files to this repository.

## Run it

Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
